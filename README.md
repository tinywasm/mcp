A low-level, protocol-only Go implementation of the Model Context Protocol (MCP). This library focuses on the core JSON-RPC protocol compliance and minimal transport handling, suitable for high-performance applications and tinygo compatibility.

## Key Features

- **Lean**: No unnecessary abstractions or third-party dependencies.
- **Protocol-First**: Implements the core MCP JSON-RPC messages and session lifecycle.
- **WASM Compatible**: Optimized for use with WebAssembly and `tinywasm`.
- **Stateless Server**: Core server logic is stateless; session state management is provided as a reference implementation.

## Installation

```bash
go get github.com/tinywasm/mcp
```

## Quickstart

### Creating a Server

```go
package main

import (
	"context"
	"github.com/tinywasm/mcp"
)

func main() {
	// Create a new MCP server
	s := mcp.NewMCPServer("My Server", "1.0.0")

	// Add a tool
	tool := mcp.NewTool("echo", "Echoes input", mcp.ToolInputSchema{
		Type: "object",
		Properties: map[string]any{
			"message": map[string]any{"type": "string"},
		},
		Required: []string{"message"},
	})

	// Add tool handler
	s.AddTool(tool, func(ctx context.Context, req mcp.CallToolRequest) (*mcp.CallToolResult, error) {
		args := req.GetArguments()
		msg := args["message"].(string)
		return mcp.NewToolResultText(msg), nil
	})

	// Use with your preferred transport (e.g. HTTP, SSE, Stdio)
	// Example usage with a request handler:
	handler := mcp.NewRequestHandler(s)
	// ... wire up handler to transport ...
}
```

## Core Concepts

### Types
All MCP protocol types are defined in `types.go`, following the JSON-RPC 2.0 specification.

### Server
The `MCPServer` struct manages registered tools and handles incoming `initialize`, `ping`, and `tools/call` requests.

### Client
The `Client` struct provides a high-level API to interact with MCP servers over any `mcp.Interface` transport.

### Transports
Standard transports like `StreamableHTTP` (SSE-based) are provided in the package.
