Lean Go implementation of the [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) over JSON-RPC 2.0. Designed to be simple to adopt — define tools as plain structs, no builders or boilerplate.

## Installation

```bash
go get github.com/tinywasm/mcp
```

## Quickstart

### 1. Define your tools as plain structs

```go
tools := []mcp.Tool{
    {
        Name:        "greet",
        Description: "Returns a greeting message",
        Parameters: []mcp.Parameter{
            {
                Name:        "name",
                Description: "The name to greet",
                Required:    true,
                Type:        "string",
            },
        },
        Execute: func(args map[string]any) {
            name := args["name"].(string)
            fmt.Println("Hello,", name)
        },
    },
}
```

### 2. Implement `ToolProvider`

```go
type MyHandler struct{}

func (h *MyHandler) GetMCPTools() []mcp.Tool {
    return tools
}
```

### 3. Wire up the Handler

```go
exitChan := make(chan bool)

handler := mcp.NewHandler(
    mcp.Config{
        Port:          "3030",
        ServerName:    "My MCP Server",
        ServerVersion: "1.0.0",
    },
    []mcp.ToolProvider{&MyHandler{}},
    myTUI,   // implements RefreshUI()
    mySSEHub, // implements Publish([]byte, string) + http.Handler
    exitChan,
)

handler.Serve() // blocks until exitChan receives
```

## Core Types

### `Tool` — the user-facing definition

```go
type Tool struct {
    Name        string
    Description string
    Parameters  []Parameter
    Execute     func(args map[string]any)
}
```

### `Parameter` — describes a single input

```go
type Parameter struct {
    Name        string
    Description string
    Required    bool
    Type        string   // "string" | "number" | "boolean"
    EnumValues  []string // optional: restrict allowed values
    Default     any      // optional: default value
}
```

### `ToolProvider` — the registration interface

```go
type ToolProvider interface {
    GetMCPTools() []Tool
}
```

## Reading Arguments in Execute

```go
Execute: func(args map[string]any) {
    // String
    name := args["name"].(string)

    // Number (JSON numbers come as float64)
    count := int(args["count"].(float64))

    // Boolean
    verbose := args["verbose"].(bool)
},
```

## Logging and Binary Output

Implement `Loggable` on your handler to receive a logger injected before each tool call:

```go
type Loggable interface {
    Name() string
    SetLog(logger func(message ...any))
}

// Usage inside Execute:
h.Logger("Processing file:", path)

// Binary output (e.g. screenshot PNG):
h.Logger(mcp.BinaryData{
    MimeType: "image/png",
    Data:     pngBytes,
})
```

## Advanced: Low-Level Server

For direct JSON-RPC server control (without `Handler`), use `MCPServer`:

```go
s := mcp.NewMCPServer("My Server", "1.0.0", mcp.WithToolCapabilities(true))

// Register a tool with full handler func
s.AddToolFromUser(mcp.Tool{
    Name:        "echo",
    Description: "Echoes input",
    Parameters: []mcp.Parameter{
        {Name: "message", Type: "string", Required: true},
    },
}, func(ctx context.Context, req mcp.CallToolRequest) (*mcp.CallToolResult, error) {
    msg := req.GetString("message", "")
    return mcp.NewToolResultText(msg), nil
})

// Wire to StreamableHTTP transport
mcpServer := mcp.NewStreamableHTTPServer(s,
    mcp.WithEndpointPath("/mcp"),
    mcp.WithStateLess(true),
)
http.Handle("/mcp", mcpServer)
http.ListenAndServe(":3030", nil)
```

```go

```

## Argument Helpers on `CallToolRequest`

```go
req.GetString("key", "default")
req.GetInt("key", 0)
req.GetBool("key", false)
req.GetArguments()       // map[string]any
req.BindArguments(&dst)  // unmarshal into a struct
```
