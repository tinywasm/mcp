# Stage 9 — session.go

Session management belongs to `tinywasm/user`.
`tinywasm/mcp` is protocol-only — it stores the session ID (string) in context
and delegates session lifecycle to the caller.

## 9.1 — ContextWithSession: store ID only

```go
// Before
import "context"
func ContextWithSession(ctx context.Context, s ClientSession) context.Context {
    return context.WithValue(ctx, sessionKey{}, s)
}
func SessionFromContext(ctx context.Context) (ClientSession, bool) {
    s, ok := ctx.Value(sessionKey{}).(ClientSession)
    return s, ok
}

// After
import "github.com/tinywasm/context"

const CtxKeySessionID = "mcp.session_id"

func ContextWithSessionID(ctx *context.Context, sessionID string) {
    ctx.Set(CtxKeySessionID, sessionID)
}
func SessionIDFromContext(ctx *context.Context) string {
    return ctx.Value(CtxKeySessionID)
}
```

Session IDs are generated by `tinywasm/unixid`:
```go
id, _ := unixid.NewUnixID()
sessionID := id.GetNewID() // e.g. "1718000000000000000"
```

The `ClientSession` object (connection state, channel, etc.) lives in the caller
(server layer / tinywasm/user). MCP only needs the ID to route notifications.

## 9.2 — Remove SessionFromContext

`SessionFromContext` returned a `ClientSession` interface — delete it.
Callers that need the full session object must maintain their own registry,
keyed by the session ID string.

## 9.3 — SendNotification: map[string]any → fmt.Fielder, allow nil

```go
// Before
func SendNotification(ctx context.Context, method string, params map[string]any) error

// After
func SendNotification(ctx *context.Context, method string, params fmt.Fielder) error
```

`params` may be `nil` for notifications that carry no data
(e.g. `notifications/tools/list_changed`).

## 9.4 — ClientSession interface: keep minimal

`ClientSession` remains the transport-level abstraction:

```go
type ClientSession interface {
    SessionID() string
    NotificationChannel() chan<- JSONRPCNotification
    Initialized() bool
    Initialize()
}
```

No context methods, no registry — pure transport contract.
`tinywasm/user`'s session maps to this via `SessionID() string`.

## 9.5 — Remove imports

Delete: `"context"` (stdlib)
Add: `"github.com/tinywasm/context"`, `"github.com/tinywasm/fmt"`
