# Stage 7 — request_handler.go

## 7.1 — Replace stdlib context

```go
// Before
import "context"
ctx = context.WithValue(ctx, headerKey{}, headers)
v  := ctx.Value(headerKey{}).(map[string]string)

// After
import "github.com/tinywasm/context"
ctx.Set("mcp.header.authorization", token)
token := ctx.Value("mcp.header.authorization")
```

Only strings in context. Two keys are sufficient:

```go
const (
    CtxKeyUserID    = "mcp.user_id"
    CtxKeySessionID = "mcp.session_id"
)
```

`auth_token` is **not stored in context** — it is extracted from the HTTP header,
passed directly to `Authorizer.Authorize(token)`, and discarded.
Only the resulting `userID` string enters context.

Do not import `tinywasm/user` into mcp — mcp is protocol-only and must not
depend on domain types (`User`, `Role`, `Permission`). The user ID string
is sufficient for tool handlers to identify the caller.

## 7.2 — Replace json.Unmarshal

```go
// Before
json.Unmarshal(message, &req)

// After
json.Decode(message, &req)
```

All target types must implement `fmt.Fielder` — generated by ormc in Stage 5.
Types used as decode targets: `initializeParams`, `callToolParams`, `rpcRequest`.

## 7.3 — Remove imports

Delete: `"context"`, `"encoding/json"`, `"net/http"` (if only used for context, not HTTP)
