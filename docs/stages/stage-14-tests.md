# Stage 14 — Tests

## 14.1 — Remove broken tests

Delete any test that:
- imports `"encoding/json"`
- uses `map[string]any` for arguments or responses
- calls `SessionFromContext` (removed in Stage 9)
- calls `GetArguments()`, `GetString()`, `GetBool()` (removed in Stage 6)
- uses `json.RawMessage`
- references `ProtocolTool`, `NewProtocolTool`, `CallToolRequest`, `CallToolResult`

## 14.3 — Bind / SafeFields test

```go
// searchArgs is generated by ormc (Schema, Pointers, Validate)
func TestBind_Valid(t *testing.T) {
    req := &mcp.Request{}
    req.Params.Arguments = `{"query":"hello","limit":10}`
    var args searchArgs
    if err := req.Bind(&args); err != nil {
        t.Fatal(err)
    }
    if args.Query != "hello" || args.Limit != 10 {
        t.Fatal("unexpected values")
    }
}

func TestBind_Invalid(t *testing.T) {
    req := &mcp.Request{}
    req.Params.Arguments = `{"query":"","limit":200}`
    var args searchArgs
    if err := req.Bind(&args); err == nil {
        t.Fatal("expected validation error")
    }
}
```
