# Stage 4 — types.go simplification

Remove all `map[string]any`, custom marshalers, and `encoding/json`.

## 4.1 — RequestId: single string type

JSON-RPC 2.0 allows string or number IDs. tinywasm/mcp uses string only.
IDs are generated by `tinywasm/unixid` — always strings.

```go
// Before: union type with custom marshaling
type RequestId struct{ value any }

// After: plain string alias
type RequestId = string
```

Breaking change: callers using numeric IDs must switch to string.

## 4.2 — Meta: remove AdditionalFields

```go
// Before
type Meta struct {
    ProgressToken    any
    AdditionalFields map[string]any
}

// After — move to model.go with ormc:formonly
// ormc:formonly
type Meta struct {
    ProgressToken string `json:",omitempty"`
}
```

`ProgressToken` changes from `any` to `string`.
`json:",omitempty"` omits the field when empty without renaming
(`progress_token` is the auto key — but MCP spec uses `progressToken`
so add the tag: `json:"progressToken,omitempty"`).

## 4.3 — NotificationParams: remove AdditionalFields

```go
// Before
type NotificationParams struct {
    Meta             map[string]any
    AdditionalFields map[string]any
}

// After — move to model.go with ormc:formonly
// ormc:formonly
type NotificationParams struct {
    Meta string `json:"_meta,omitempty"`
}
```

`_meta` starts with underscore — always requires explicit `json:"_meta"` tag.

## 4.4 — Delete custom marshalers

Remove `MarshalJSON`/`UnmarshalJSON` methods from:
- `Meta`
- `NotificationParams`
- `RequestId` (no longer needed — it's a string alias)

`tinywasm/json` handles these structs directly via ormc-generated `Schema()`/`Pointers()`.

## 4.5 — Remove http.Header from public types

`http.Header` appears in 5 public structs tagged `json:"-"` (never serialized).
It is used only in `.back.go` HTTP handlers to pass request headers.
Remove from public types entirely — HTTP handlers read headers directly from
`*http.Request` before calling the WASM-safe handler:

```go
// Remove from: ListToolsRequest, CallToolRequest, JSONRPCRequest,
//              InitializeRequest, PingRequest
Header http.Header `json:"-"`  // DELETE
```

HTTP handler extracts what it needs (e.g. Authorization) into context before
calling the core handler. The core never sees `http.Header`.

## 4.6 — Remove ServerCapabilities.Experimental / ClientCapabilities.Experimental

Both carry `Experimental map[string]any` — not used, blocks TinyGo.
Delete both fields. If experimental features are needed in the future,
they must be added as typed fields.

## 4.8 — Clean up types.go imports

Remove: `"encoding/json"`, `"fmt"` (stdlib), `"maps"`, `"strconv"`, `"net/http"`

Update all fields referencing the old types to use the new simple types.
