# Stage 11 — handler.go

## 11.1 — Split HTTP-bound code to handler.back.go

`handler.go` contains both WASM-safe logic and HTTP-specific code.
Move all `net/http`-dependent code to `handler.back.go`:

```go
//go:build !wasm
```

WASM-safe file keeps no build tag.

## 11.2 — Replace stdlib context

```go
// Before — stdlib
import "context"
func (h *Handler) Handle(ctx context.Context, ...) error {
    v := ctx.Value(someKey{})
}

// After — tinywasm
import "github.com/tinywasm/context"
func (h *Handler) Handle(ctx *context.Context, ...) error {
    v := ctx.Value(CtxKeySessionID)
}
```

All context operations use `ctx.Set(key, value)` / `ctx.Value(key)` — string keys only.
Use constants from `request_handler.go`:
```go
ctx.Set(CtxKeySessionID, sessionID)
ctx.Set(CtxKeyUserID,    userID)
```

## 11.3 — Replace json.Marshal / json.Unmarshal

```go
// Before
data, err := json.Marshal(result)

// After
var s string
err := json.Encode(result, &s)
data := []byte(s)
```

All encode/decode targets must implement `fmt.Fielder` (generated by ormc).

## 11.4 — Remove duplicate MethodFunc / methodFunc

`handler.go` defines two identical function types, one exported and one unexported:

```go
type MethodFunc func(ctx context.Context, params []byte) (any, error)  // exported
type methodFunc func(ctx context.Context, params []byte) (any, error)  // private — DELETE
```

The private copy exists only because the map stores `methodFunc`.
Keep only `MethodFunc` (exported), store it directly in the map.
Remove the cast on line 88: `h.customMethods[name] = methodFunc(fn)` → `h.customMethods[name] = fn`.

Return type `any` → `fmt.Fielder` (registered methods must return a typed value).

## 11.5 — Replace anonymous inline structs

`handler.go` and `request_handler.go` define anonymous structs for JSON peeking:

```go
// handler.go ~189
var peek struct { Method string `json:"method"` }

// request_handler.go ~13
var base struct { ID string; Method string; Params json.RawMessage }
```

Replace with named types in `model.go` (with `// ormc:formonly`):
- `rpcRequest` (already defined in Stage 5) covers both cases.

Delete: `"context"`, `"encoding/json"` (stdlib)
Add: `"github.com/tinywasm/context"`, `"github.com/tinywasm/json"`, `"github.com/tinywasm/fmt"`
