# PLAN: Fix MCP tools/call arguments parsing and inputSchema serialization

## Context

The `github.com/tinywasm/mcp` package exposes a JSON-RPC 2.0 MCP server.
Two bugs prevent MCP clients (Claude Code, Cursor, etc.) from calling tools correctly:

1. **Bug A (critical):** `tools/call` rejects valid requests with `"Invalid params: json decode expected string"` when `arguments` is a JSON object (standard MCP format).
2. **Bug B (secondary):** `tools/list` returns `inputSchema` as a JSON-encoded string instead of an inline JSON object, violating the MCP spec.

Both bugs share the same root cause: two fields in `model.go` are typed as plain `string` but must be `fmt.RawJSON`. The `ormc` code generator emits `FieldText` for `string` fields and `FieldRaw` for `fmt.RawJSON` fields. `FieldText` makes the JSON encoder/decoder expect a quoted string; `FieldRaw` handles raw JSON values inline.

---

## Root Cause

### `fmt.RawJSON` vs `string`

In `github.com/tinywasm/fmt` (`field.go`):
- `type RawJSON = string` — type alias, same underlying type as `string`
- `ormc` detects `fmt.RawJSON` by full qualified type name and emits `FieldRaw` in the generated `Schema()` method
- `tinywasm/json` parser: `FieldText` expects a quoted JSON string (`"..."`); `FieldRaw` accepts any JSON value (object, array, string, number)
- `tinywasm/json` encoder: `FieldText` wraps the value in quotes; `FieldRaw` emits the value inline as-is

### Bug A — `CallToolParams.Arguments` (`model.go`)

```go
// CURRENT (wrong):
type CallToolParams struct {
    Name      string
    Arguments string `json:",omitempty"`   // generates FieldText → expects quoted string
}
```

When a client sends `{"arguments": {"url": "..."}}`, the parser reads `{` expecting a quoted string and returns "json decode expected string".

### Bug B — `toolEntry.InputSchema` (`model.go`)

```go
// CURRENT (wrong):
type toolEntry struct {
    Name        string
    Description string `json:",omitempty"`
    InputSchema string `json:"inputSchema,omitempty"`  // generates FieldText → wraps JSON in quotes
}
```

When encoding tool entries in `handleListTools()`, the encoder sees `InputSchema` as `FieldText` and wraps its already-valid JSON content in quotes. Result: `"inputSchema": "{\"type\":\"object\",...}"` instead of `"inputSchema": {"type":"object",...}`.


## Tests That Reproduce the Bugs

Before applying any fix, add the following tests to `tests/mcp_test.go`. These tests **must fail** on the current code and **must pass** after the fix is applied. This validates the regression coverage.

### Test for Bug A — `tools/call` with `arguments` as JSON object

```go
// TestToolCall_ArgumentsAsObject verifies that tools/call accepts arguments
// as a JSON object (MCP spec), not only as a quoted string.
// This test FAILS before the fix (model.go Arguments string → fmt.RawJSON).
func TestToolCall_ArgumentsAsObject(t *testing.T) {
	srv, _ := mcp.NewServer(mcp.Config{Name: "test", Version: "1.0.0", Auth: mcp.OpenAuthorizer()}, nil)
	srv.AddTool(mcp.Tool{
		Name:     "echo",
		Resource: "test",
		Action:   'r',
		Execute: func(ctx *context.Context, req mcp.Request) (*mcp.Result, error) {
			return mcp.Text("ok"), nil
		},
	})
	var ctx context.Context

	// MCP spec: arguments MUST be a JSON object, not a quoted string
	req := []byte(`{"jsonrpc":"2.0","id":"1","method":"tools/call","params":{"name":"echo","arguments":{}}}`)
	resp := srv.HandleMessage(&ctx, req)

	if resp == nil {
		t.Fatal("expected response, got nil")
	}

	body := encodeResponse(resp)

	if contains(body, "json decode expected string") {
		t.Fatalf("Bug A not fixed: server rejected JSON object arguments with parse error.\nResponse: %s", body)
	}
	if contains(body, `"error":`) {
		t.Fatalf("expected success response, got error: %s", body)
	}
}
```

### Test for Bug B — `tools/list` returns `inputSchema` as JSON object

```go
// TestListTools_InputSchemaIsObject verifies that tools/list returns inputSchema
// as an inline JSON object, not as a quoted JSON string.
// This test FAILS before the fix (model.go InputSchema string → fmt.RawJSON).
func TestListTools_InputSchemaIsObject(t *testing.T) {
	srv, _ := mcp.NewServer(mcp.Config{Name: "test", Version: "1.0.0", Auth: mcp.OpenAuthorizer()}, nil)
	srv.AddTool(mcp.Tool{
		Name:        "search",
		Description: "Search something",
		InputSchema: `{"type":"object","properties":{"query":{"type":"string"}}}`,
		Resource:    "items",
		Action:      'r',
		Execute: func(ctx *context.Context, req mcp.Request) (*mcp.Result, error) {
			return mcp.Text("ok"), nil
		},
	})
	var ctx context.Context

	req := []byte(`{"jsonrpc":"2.0","id":"1","method":"tools/list","params":{}}`)
	resp := srv.HandleMessage(&ctx, req)

	if resp == nil {
		t.Fatal("expected response, got nil")
	}

	body := encodeResponse(resp)

	// inputSchema must NOT appear as a quoted string (i.e. "inputSchema":"..." is wrong)
	// It must appear as an inline object (i.e. "inputSchema":{"type":... is correct)
	if contains(body, `"inputSchema":"{`) {
		t.Fatalf("Bug B not fixed: inputSchema is a quoted string instead of a JSON object.\nResponse: %s", body)
	}
	if !contains(body, `"inputSchema":{"type"`) {
		t.Fatalf("expected inputSchema as inline object, got: %s", body)
	}
}
```

## Implementation Steps

### Step 1 — Edit `model.go`

File: `model.go` in the root of the `github.com/tinywasm/mcp` module.

Apply two changes:

**Change 1** — `CallToolParams.Arguments`: change type from `string` to `fmt.RawJSON`

```go
// BEFORE:
type CallToolParams struct {
    Name      string
    Arguments string `json:",omitempty"`
}

// AFTER:
type CallToolParams struct {
    Name      string
    Arguments fmt.RawJSON `json:",omitempty"`
}
```

**Change 2** — `toolEntry.InputSchema`: change type from `string` to `fmt.RawJSON`

```go
// BEFORE:
type toolEntry struct {
    Name        string
    Description string `json:",omitempty"`
    InputSchema string `json:"inputSchema,omitempty"`
}

// AFTER:
type toolEntry struct {
    Name        string
    Description string `json:",omitempty"`
    InputSchema fmt.RawJSON `json:"inputSchema,omitempty"`
}
```

The import `"github.com/tinywasm/fmt"` is already present in `model.go` — no new imports needed.
