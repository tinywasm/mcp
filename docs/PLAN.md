## Pending stages — execute these

### Stage 9 — [session.go](../stages/stage-09-session.md)

**Issue:** `SendNotification` has an extra `session ClientSession` parameter.

```go
// Current (wrong)
func SendNotification(ctx *context.Context, session ClientSession, method string, params fmt.Fielder) error

// Required (stage 9.3)
func SendNotification(ctx *context.Context, method string, params fmt.Fielder) error
```

`mcp` does not own a session registry. The function becomes a protocol-level helper
that builds the notification. Channel routing stays in the server layer (server.back.go).

**Files:** `session.go`, any internal callers in `server.go`/`server.back.go`
